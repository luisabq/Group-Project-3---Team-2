Ashra and the Shattered Key
Release To Manufacturing (RTM) – Final Build
 Team 2: Game Invaders
________________


1. Overview
Ashra and the Shattered Key is a third-person puzzle platformer where players travel between planets, using traversal-based mechanics to recover fragments of a broken key.
This build represents our final version of the project. At this point, all major systems, levels, art, and audio have been implemented and brought to a polished state for presentation.

2. Open the extracted folder

3. Controls
Keyboard & Mouse
   * WASD / Arrow Keys → Movement
   * Mouse → Camera
   * Space → Jump
   * Shift → Sprint
   * 1 → Equip Grapple Arm
   * 2 → Equip Steam Arm
   * Right Click → Aim Mode
   * Left Click → Use Tool
   * E → Interact
________________


Controller (Xbox)
   * Left Stick → Movement
   * Right Stick → Camera
   * A → Jump
   * Press Left Stick → Sprint
   * LB / RB → Switch Tools
   * LT → Aim
   * RT → Use Tool
   * X → Interact

4. Gameplay Summary
The game begins in a central hub (the ship), where the player can choose between three levels:
   * Ruins — Activate timed receptors to open portals
   * Heist — Trigger platforms to move through the space
   * Incinerator — Jump between moving ships to reach the goal
Each level ends with collecting a key fragment, which contributes to overall progression. The levels can be completed in any order.
________________


5. Core Mechanics
The gameplay is built around a small set of mechanics that are reused across levels:
   * Grapple-based traversal
   * Steam-powered activation system
   * Timed puzzle interactions
   * Environmental navigation challenges
Each level uses these systems differently to create variation without introducing new mechanics.

   * Single-player, third-person experience
   * Hub world with 3 playable levels
   * Non-linear level progression
   * 7–10 minute critical path

   * Visual “How To Play” instructions
   * Collectible system (key fragments)
   * Environmental challenge (non-combat gameplay)
   * Full controller and keyboard support

________________


7. Narrative Elements
The player controls Ashra, a space pirate captain traveling between planets to recover lost key fragments.
Story elements are delivered through:
   * Environmental storytelling
   * Hub interactions
   * Opening and closing cutscenes
________________


8. Known Issues (Minor)
The game is stable and can be completed without interruption. Some small issues may still appear, such as:
   * Minor UI inconsistencies
   * Occasional visual clipping
   * Slight confusion in navigation in certain areas
None of these prevent the player from finishing the game.
