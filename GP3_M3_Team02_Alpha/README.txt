README – Alpha Build
Ashra and the Shattered Key
 Team 2: Game Invaders
________________


Overview
Ashra and the Shattered Key is a third-person puzzle platformer focused on movement and environmental interaction. The player travels between different levels using a central hub and uses a small set of tools to activate systems, move through the space, and reach the end of each level.
This Alpha build is a complete, playable version of the game with all core mechanics and levels included.
________________


Objective
Each level has a clear goal: move through the environment, activate the required systems, and reach the end to collect a key fragment. After finishing a level, the player returns to the hub and can choose another one.
Levels can be completed in any order.
________________


Controls
Keyboard & Mouse
* WASD – Move
* Mouse – Camera
* Space – Jump
* Shift – Sprint
* 1 – Grapple Tool
* 2 – Steam Tool
* Right Click (Hold) – Aim
* Left Click – Use Tool
* E – Interact
* R / T – Place Marker / Activate Recall
________________


Controller (Xbox)
* Left Stick – Move
* Right Stick – Camera
* A – Jump
* Press Left Stick – Sprint
* X – Interact
* LB / RB – Switch Tools
* LT – Aim
* RT – Use Tool
* Y / X – Place Marker / Activate Recall
________________


Core Mechanics
* Grapple – Used to move quickly across gaps or reach higher areas
* Steam Tool – Activates objects like receptors and platforms
* Timed Systems – Some actions must be completed within a short time
* Portals – Open when all required conditions are met
* Recall – Allows the player to return to a previously placed point
________________


Levels in This Build
* Hub (Ship) – Central area for selecting levels
* Ruins – Timed receptor puzzle that opens portals
* Heist – Platform-based traversal using activation systems
* Incinerator – Movement between ships with more timing-based jumps

Known Issues
